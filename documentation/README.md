# Documentation

The documentation has two layers:

- `es/` — faithful Spanish transcriptions of the original documents. This is the source text.
  Original spelling and orthographic errors are preserved. The author line names Juan Camilo Rivera.
- `en/` — English translations. These are reading aids, not the original documents.

## Rule

No report or lesson in this archive requires the reader to understand Spanish. Spanish quotations
used in an English document are translated at the point of use.
