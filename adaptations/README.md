# Adaptations

This directory holds non-behavioral additions for learning. It never replaces `original/`. Every
adaptation is clearly labeled and can be removed without touching the historical evidence.

## Modern class version

The historical class rung is missing; the modern class version is described in this file under
`construction-11` (encapsulation), `construction-12` (polymorphism) and `construction-13`
(composition), and will live in the laboratory at
<https://github.com/DaydreamsDev/guerra-de-caballos-lab>. The same applies to every other step not
present in the originals: modular programming, abstract data types, object-oriented programming,
generic programming and the lenses were never intended to be worked out in the 2008 files. They are
curriculum extensions, not missing historical artifacts.

The class version is split across three lessons:

- `construction-11` — encapsulation: a class with an invariant.
- `construction-12` — polymorphism: a `Piece` interface and dynamic dispatch.
- `construction-13` — composition: composition over inheritance.

Until that repository exists, this file is the pointer; the archive does not contain the
reconstruction.

## Planned adaptations

- `port/` — modern C++ build, behavior preserved, with tests.

Neither exists yet. When they are created, they will be separate from `original/` and will not be
used as evidence for the historical claims.
