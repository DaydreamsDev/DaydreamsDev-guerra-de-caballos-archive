# 00 — Provenance

## Origin

This archive preserves the 2007–2008 work *Guerra de Caballos* by Juan Camilo Rivera. The precursor
was written in 2007; the two-knight game was written in 2008. The public archive is a restored
edition prepared in 2026.

The raw files are kept in a private local vault. That vault is not published. The public archive
contains the restored edition only.

## Attribution policy

The archive is published as the sole work of Juan Camilo Rivera.

Public source headers use `AUTHOR: Juan Camilo Rivera` in `variant-01` through `variant-04`;
`variant-00` uses `Author: Juan Camilo Rivera`. This is a formatting change, not a code change. It is
documented in [`06-restoration.md`](06-restoration.md).

## License

The archive is released under the MIT license. The original precursor header carried a different

## What is included

- The surviving source files, restored to readable encoding and line endings.
- The historical documentation, transcribed to Markdown.
- Provenance, inventory, taxonomy, lineage, build status, known issues and restoration reports.
- Checksums for the published archive files.

## What is excluded

- Compiled binaries and debug symbols.
- Integrated development environment project metadata.
- Private material retained in the raw vault.
- Material outside the archive scope.
- Any reconstruction of missing code.

## Evidence boundary

The archive records what survived. It does not claim that the surviving set is complete. The
class-based implementation is missing; see
[`variant-05-classes-missing/README.md`](original/variant-05-classes-missing/README.md).
